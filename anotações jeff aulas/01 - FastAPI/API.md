A aplicação que permite que dois softwares distintos conversem entre si por meio de requisições

Na prática funciona assim

Request: Programa 1 envia um pedido -> Processamento: A API leva esse pedido ao servidor do Programa 2 -> Resposta: O servidor processa e a API traz os dados de volta, seja a resposta do pedido os dados num sucesso (200) ou algum erro
